01

El Alcance de la Integración

DESARROLLO BACKEND

Automatización integral: la tarjeta digital del cliente en su Apple/Google Wallet se actualizará en tiempo real al registrarse su check-in en el sistema de BYB.

BASE DE DATOS Y LÓGICA DE NEGOCIO
  • Registro de Miembros: Creación de base de datos para almacenar el estatus de membresía e historial de uso de cada usuario.
  • Contador de Usos: Algoritmo que registra los usos activos de botas y bloquea el agendamiento al alcanzar el límite de 8 al mes.
  • Cron Job de Reset: Script automatizado que se ejecuta el primer día de cada mes para reiniciar el contador a 8 usos.
API WALLET Y MÓDULO DE ESCANEO
  • Integración de API de Pases: Conexión del CRM/Booking de BYB con PassKit/PassNinja para generar y actualizar tarjetas dinámicamente ("Usos restantes: 7/8").
  • Módulo de Escáner en Web: Creación de un panel web responsivo para la computadora de recepción, permitiendo al staff escanear el QR del cliente con la webcam y descontar usos de forma directa en el sistema.
